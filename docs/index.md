# Imagies

Imagies stages and edits still images, ranks them with CLIP, detects objects with YOLO, and runs Stable Diffusion through stable-diffusion.cpp. The same service exposes REST and streamable HTTP MCP.

| To do this | Read |
| --- | --- |
| Pick an image, run the container, and install models | [Deployment](deployment.md) |
| Stage an image and make your first request | [REST API](api.md) |
| Connect an MCP client and call tools | [MCP](mcp.md) |
| Build and test the service and its docs | [Development](development.md) |
